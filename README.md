## 🏃 奔跑逐月（攝影機原地跑步，1～3 人）

按上方「奔跑逐月」開啟面板，選人數、距離後按「開始」（或舉起雙手 1 秒）。倒數「3、2、1、跑！」後在鏡頭前原地跑步，先「逐到明月」的人獲勝，接著播放「圓滿祝福」燈光秀。

| 人數 | 你控制的燈 | 燈組上會看到 |
|---|---|---|
| 1 人 | 雲羊 | 光階梯一階階往上亮、雲羊由下往上亮起，抵達明月時明月爆亮＋冷焰火；成績會記錄最佳秒數 |
| 2 人 | 小羊（左）、小羊（右） | 各自的小羊越跑越亮、每踏一步跳一下；光階梯跟著領先者 |
| 3 人 | 小羊（左）、大羊、小羊（右） | 同上，大羊由下往上亮起、羊角捲開 |

- **攝影機**：需 HTTPS（GitHub Pages 網址即可），第一次會下載姿勢辨識模型（約 10～20 秒），影像只在瀏覽器裡處理、不會上傳
- **站位**：多人時鏡頭畫面分成格子，左到右＝玩家 1～3；建議站在 2～4 公尺外，讓全身（至少到膝蓋）入鏡
- **偵測方式**：優先看膝蓋交替抬高，其次腳踝，腳沒入鏡時改看手臂擺動
- **距離**：短 30 步／中 50 步／長 80 步；**靈敏度**：偵測不到調「高」、太容易多算調「低」
- **沒有攝影機**：鍵盤玩家 1 按 `A` `S`、玩家 2 按 `K` `L`、玩家 3 按 `←` `→` 交替按；手機可直接點跑道
